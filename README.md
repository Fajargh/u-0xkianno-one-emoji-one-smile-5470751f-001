One emoji, one smile: this program writes exactly one emoji — 🤗, the hugging face — to `/output/entry.txt`. An open-armed, welcoming smile: warm at first glance, readable by a stranger of any age or background, and chosen rather than the first smiley that comes to mind. Friendly from a stranger, with no irony, no in-joke, and no flirtation — just a hug offered.

## Run it

```sh
python3 main.py
```
